# Hostidian API (Go)

The HTTP API of Hostidian: auth and sessions, users, workspaces, the page tree, permissions, the
SSE event stream and the collab-token issuer. Module `hostidian/backend`, Go 1.26, Postgres 17.
The binding rules are in [`../docs/conventions.md`](../docs/conventions.md); the public contract is
[`../api/openapi.yaml`](../api/openapi.yaml), the service-to-service one
[`../api/internal.yaml`](../api/internal.yaml).

## Layout

```
cmd/hostidian/            main: config -> migrate -> serve (public :8080 /api, internal :8081)
migrations/               goose SQL (00001 schema = contract, 00002 permission resolver), embedded
queries/*.sql             every SQL statement of the app (sqlc input, parameterized)
internal/
  config/                 env parsing, derived values (cookie Secure flag, collab ws URL)
  db/                     pgx pool, goose runner, WithTx/InTx helpers
  db/sqlcgen/             GENERATED by sqlc (checked in)
  httpapi/                chi router, middleware, handlers_*.go, internal router
  httpapi/gen/            GENERATED by oapi-codegen (checked in): ServerInterface + models + embedded spec
  perm/                   THE permission resolver (Go face of the SQL function effective_page_roles)
  events/                 in-process SSE broker with per-subscriber permission filtering
  auth/                   sessions, argon2id, login/register/invites, password reset, admin, rate limit
  oidc/                   optional OIDC (PKCE/state/nonce) + the pure account-linking policy
  workspaces/             workspaces, members, invites
  pages/                  page tree, trash, favorites, sharing (grants), collab tokens
  collabclient/           POST {collab}/internal/disconnect (best effort, async)
  deps/                   dependency bundle shared with domain packages
  apperr/                 error type that maps 1:1 onto the error envelope
  validate/ tokens/       input rules, random tokens
  testutil/               shared testcontainers Postgres + SQL fixture builder
```

## Generate, build, run, test

```sh
cd backend
go generate ./...                  # oapi-codegen + sqlc (both run via `go tool`, versions pinned in go.mod)
test -z "$(gofmt -l .)" && go vet ./... && go test ./... -count=1
go run ./cmd/hostidian             # needs the env below
```

The first `go tool sqlc` on a machine compiles sqlc and its cgo SQL parser (a few minutes, cached
afterwards); `go build ./...` and the Docker image never touch the tools.

Generated code **is checked in**, so a fresh clone builds without running the generators:
`internal/httpapi/gen/api.gen.go` and `internal/db/sqlcgen/*.go`. Re-run `go generate ./...` after
touching `../api/openapi.yaml`, `migrations/` or `queries/`.

`scripts/gen-openapi.sh` runs oapi-codegen against `../api/openapi.yaml`. Keep the contract YAML-1.1-safe
(quote any description containing `: `, `?` or `…` inside flow mappings): the Go parser is stricter than the JS tooling.

Tests use [testcontainers-go](https://golang.testcontainers.org/) with `postgres:17-alpine`: one
container per test package, one throw-away database per test (cloned from a migrated template), so
Docker must be running. `HOSTIDIAN_SKIP_DOCKER_TESTS=1` skips the database tests.

### Environment

See `../.env.example`. Required: `DATABASE_URL`, `COLLAB_JWT_SECRET`, `INTERNAL_TOKEN`, `APP_SECRET`.
Everything else has a default:

| Variable | Default | Notes |
|---|---|---|
| `PUBLIC_URL` | `http://localhost:8080` | cookie `Secure` flag iff https; Origin allow-list; invite/reset/OIDC links |
| `ALLOWED_ORIGINS` | – | extra browser origins for the CSRF check (dev: `http://localhost:3000`) |
| `API_ADDR` / `INTERNAL_ADDR` | `:8080` / `:8081` | `GET /healthz` on both |
| `COLLAB_INTERNAL_URL` | – | empty disables the revocation calls to collab |
| `COLLAB_PUBLIC_URL` | `ws(s)://<PUBLIC_URL host>/collab` | returned by `POST /pages/{id}/collab-token` |
| `DATA_DIR`, `MAX_UPLOAD_MB` | `./data`, `50` | used by the files feature (wave 2) |
| `OIDC_ISSUER_URL`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_NAME` | – | OIDC is on iff the first three are set; redirect URI = `${PUBLIC_URL}/api/auth/oidc/callback` |
| `LOG_LEVEL` | `info` | JSON logs (slog) on stdout |

## How the pieces fit

**Permissions.** The rules of conventions §3 exist exactly once, as the SQL function
`effective_page_roles(workspace, user, page_ids?)` (`migrations/00002_perm_functions.sql`, returns
`(page_id, role_rank)`; 0 none … 4 full; incl. creator ownership: `pages.created_by` is an implicit `full` grant, inherited downwards). With `page_ids` it only walks the ancestors of those pages
(O(depth)); without, it resolves the whole workspace in one recursive CTE. Everything else goes
through it: `perm.Resolve/Require` for one page (404 for none, 403 for too little, archived pages only
for `full`), `perm.ResolveMany/ResolveWorkspace` for batches, and queries that `JOIN` the function
(`queries/pages.sql`). **Never write ad-hoc permission SQL.** sqlc cannot see the function's result
columns, so call it as
`FROM effective_page_roles(@ws::uuid, @user::uuid) AS r(page_id, role_rank)` and cast
`r.page_id::uuid, r.role_rank::int`. Pass `'{}'` (never NULL) for "no pages".

**Events.** `deps.Broker.Publish(events.Event{Type, WorkspaceID, PageID, ActorID, Page|Data})` after
a mutation committed. It never blocks; each subscriber's goroutine checks the resolver before
writing (page events need `view`; `permissions.changed` reaches everyone but only reveals the page id
to those who may view it; `member.changed` skips guests; `Recipients` pins the audience, used by
`page.deleted`). `Page` summaries get the subscriber's own `role` and a masked `parentId`.

**Errors.** Services return `*apperr.Error` (`apperr.NotFound/Forbidden/Conflict/FieldError/...`);
`Server.writeError` renders the envelope and logs/hides everything else as a 500.

**Sessions.** `hostidian_session` cookie = 32 random bytes; the DB stores SHA-256. 30 day sliding
expiry, written at most every 5 minutes. The session middleware reads from the embedded OpenAPI spec
which operations are protected (`security: []` = public), so a new operation is protected by default.

**Revocation.** Grants/revokes/visibility/moves/archive/purge/member changes/disabled users call
`collabclient.Disconnect` (async, logged, no-op without `COLLAB_INTERNAL_URL`) and publish
`permissions.changed`; removed members, disabled users, revoked sessions and deleted workspaces also
lose their SSE streams.

## Adding endpoints (wave 2 pattern, no edits to existing files)

* **Public operation:** implement the generated method on `*httpapi.Server` in a new
  `internal/httpapi/handlers_<domain>.go`; it shadows the `gen.Unimplemented` 501. Take the caller
  with `s.requireUser(w, r)`, errors with `s.writeError`, bodies with `decodeJSON[T]`, replies with
  `writeJSON`. Build services lazily with `httpapi.Ext(s, "files", func() *files.Service {…})`
  (domain packages import `internal/deps`, never `internal/httpapi`).
* **Internal operation:** `func init() { httpapi.RegisterInternalRoutes(func(s *httpapi.Server, r chi.Router) { r.Put("/pages/{pageId}/content", …) }) }`
  — served at `/internal/pages/{pageId}/content` behind the bearer `INTERNAL_TOKEN` check.
* **SQL:** add `queries/<domain>.sql`, run `go generate ./...`; sqlc only adds files to `internal/db/sqlcgen`.
* **Streaming responses** (downloads, SSE) must extend the 1 minute write deadline with
  `http.NewResponseController(w).SetWriteDeadline(...)`; JSON handlers are capped by `decodeJSON` at 1 MiB,
  uploads set their own `http.MaxBytesReader`.
